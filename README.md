# 🚗 Car Rental System (Java & OOPs)

A lightweight, console-based **Car Rental System** built using **Java** to showcase core **Object-Oriented Programming (OOP)** concepts. This application manages cars, customers, and rental transactions seamlessly through an interactive command-line interface (CLI).

---

## 🌟 Key Features

* **Car Fleet Management:** Keep track of available and rented cars along with their daily rental rates.
* **Customer Management:** Register customer details and assign unique IDs for seamless booking tracking.
* **Rental System:** Book a car for a specified number of days with automatic cost calculation.
* **Return System:** Process car returns and make them available again in the system inventory.
* **Interactive CLI Interface:** Easy-to-use menu-driven terminal interface for user operations.

---

## 🛠️ Object-Oriented Programming (OOP) Concepts Used

* **Encapsulation:** Used private fields with getters and setters in classes like `Car`, `Customer`, and `Rental` to ensure data security.
* **Abstraction:** Simplified complex booking and returning logic inside the main `CarRentalSystem` class.
* **Inheritance & Polymorphism:** Scalable architecture structured for extending future features like different vehicle types (e.g., Luxury, SUV, Bike).

🚀 Getting Started
Prerequisites
Java Development Kit (JDK 8 or higher) installed on your machine.

Any code editor or IDE (e.g., VS Code, IntelliJ IDEA, Eclipse) or terminal access.

Installation & Execution
Clone the Repository

Bash
git clone [https://github.com/SamridhiK2518/Car-Rental-System-OOPS-Java.git](https://github.com/SamridhiK2518/Car-Rental-System-OOPS-Java.git)
cd Car-Rental-System-OOPS-Java
Compile the Java Code

Bash
javac main.java
Run the Application

Bash
java Main
📸 Usage Workflow
Rent a Car:

Select a car from the available fleet.

Input your customer details (Name, ID).

Enter the number of rental days.

Confirm the total price calculation to complete the reservation.

Return a Car:

Enter the car ID to process the return.

System updates the car availability status instantly.
